    Migration to 0.9¶

    feu 0.9 is a breaking release (feu is 0.x). The names that other repositories depend on are kept: from feu import compare_version, feu.imports.is_package_available, the feu.testing marks, feu.local_git.get_last_version_tag_name, and the short and long names of the CLI options -n, -v, -e, -i, -a, -p.

    Behaviour changes¶

    • A target without os and arch is no longer a no-op. find_closest_version("numpy", "2.3.0", Target("3.9")) returned "2.3.0"; it now returns "2.0.2" (the union of the platforms). install_package_closest_version uses the full current target, and the examples of the README return what they document.
    • A version is a request. "", None and a wildcard ("2.*") are accepted wherever a version is, checked against the registry and resolved. A wildcard is no longer skipped by the compatibility check; a wildcard with no match raises UnsupportedVersionError.
    • Package names are canonical (PEP 503) in the registries, the resolver registry, the pyproject reader and the PyPI functions. The sklearn resolver key is gone.
    • find-closest-version prints only the version; an unsupported request exits 1 with the message on standard error (it printed None and exited 0). check-valid-version exits 1 when the version is not valid. An invalid argument exits 2.
    • pip installs into the interpreter that runs feu (sys.executable -m pip), and a missing pip or uv raises RuntimeError before any command.
    • Wheels: macosx_*_universal2 wheels and compressed tag sets count for every platform they support. The shipped data changed for 10 macOS targets.

    Scripts that copy dev/generate_versions.py¶

    The script is replaced by one CLI call:

    feu package-versions --pyproject pyproject.toml --output dev/config/package_versions.json

    fetch_latest_{major,minor}_versions_map, read_pyproject_*, partition_package_bounds, feu.utils.io.save_json and feu.utils.mapping.sort_by_keys are kept until the repositories that copy the script are migrated.

    Examples¶

    >>> from feu.compat import Target, find_closest_version
>>> find_closest_version("numpy", "2.3.0", Target("3.9"))
'2.0.2'

    >>> from feu.install import InstallerSpec
>>> InstallerSpec("pip", arguments="-U --pre")
InstallerSpec(name='pip', arguments=('-U', '--pre'))

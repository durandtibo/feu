    feu.benchmark.find_regressions ¶

    find_regressions(
    runs: Sequence[Run],
    *,
    baseline_runs: int = 7,
    threshold: float = 50.0,
) -> list[Regression]

    Find the benchmarks slower than their recent median.

    The latest run is compared with the median of the previous runs (at most baseline_runs), which is more stable than the comparison with one run because the runners are noisy. The runs of different machines are never compared with each other: each machine has its own latest run and its own baseline.

    Parameters:

    Name Type Description Default
    runs Sequence[Run]

    The runs returned by load_runs.

    		 required
    baseline_runs int

    The maximum number of previous runs used for the median. It must be at least 1.

    		 7
    threshold float

    The slowdown in percent above which a benchmark is a regression. It must be greater than 0.

    		 50.0

    Returns:

    Type Description
    list[Regression]

    The regressions sorted by decreasing change, then by label and machine. It is empty if no machine has two runs.

    Raises:

    Type Description
    ValueError

    If baseline_runs is less than 1 or threshold is not greater than 0.
    Example 
    >>> from datetime import UTC, datetime
>>> from feu.benchmark import Run, find_regressions
>>> date = datetime(2026, 1, 1, tzinfo=UTC)
>>> runs = [Run(date, "", {"sort": 0.001}), Run(date, "", {"sort": 0.003})]
>>> find_regressions(runs)
[Regression(machine='', label='sort', latest=0.003, baseline=0.001, change=200.0)]

    feu.benchmark.load_runs ¶

    load_runs(
    storage: Path,
    *,
    days: int = 90,
    kind: str = "benchmark",
    stat: str = "median",
    label: str = "name",
) -> list[Run]

    Load the results of the runs in the window.

    Only the files that pytest-benchmark names (NNNN_*.json) are read, the other files are ignored. A run without time is dropped.

    Parameters:

    Name Type Description Default
    storage Path

    The pytest-benchmark storage directory.

    		 required
    days int

    The size of the window in days. It must be at least 1.

    		 90
    kind str

    The kind of results, "benchmark" or "import". The benchmark kind reads the statistic from the stats of pytest-benchmark; the import kind reads import_seconds_<stat> of the extra_info, and ignores the benchmarks that do not have it.

    		 'benchmark'
    stat str

    The statistic of the times: "min", "mean", "median" or "max".

    		 'median'
    label str

    The rule of the label of a benchmark. "name" is the name without the test_ prefix and the _benchmark suffix (test_sort_benchmark[10] is sort[10]), or the parameter for the import kind. "fullname" is the full name of the benchmark.

    		 'name'

    Returns:

    Type Description
    list[Run]

    The runs sorted by date then by machine.

    Raises:

    Type Description
    ValueError

    If an argument is invalid, if a result file is invalid (the message has its path), or if two benchmarks of a run have the same label.
    Example 
    >>> import json
>>> import tempfile
>>> from pathlib import Path
>>> from feu.benchmark import load_runs
>>> with tempfile.TemporaryDirectory() as tmp:
...     result = {
...         "datetime": "2999-01-01T00:00:00+00:00",
...         "benchmarks": [{"name": "test_sort_benchmark", "stats": {"median": 0.001}}],
...     }
...     _ = Path(tmp, "0001_run.json").write_text(json.dumps(result))
...     runs = load_runs(Path(tmp))
...
>>> runs[0].times["sort"]
0.001

    feu.benchmark.with_unit ¶

    with_unit(
    kind: TrendKind,
    unit: str,
    *,
    scale: float | None = None,
) -> TrendKind

    Change the unit of the times shown in the reports of a kind.

    Parameters:

    Name Type Description Default
    kind TrendKind

    The kind of benchmark results.

    		 required
    unit str

    The new unit. It is one of the keys of UNITS ("s", "ms", "us", "µs" and "ns") unless scale is given.

    		 required
    scale float | None

    The conversion from seconds to unit. If None, the scale of unit in UNITS is used.

    		 None

    Returns:

    Type Description
    TrendKind

    A copy of the kind with the unit and its scale. "us" is shown as "µs".

    Raises:

    Type Description
    ValueError

    If the unit is not in UNITS and scale is not given, or if scale is not positive.
    Example 
    >>> from feu.benchmark import BENCHMARK_KIND, with_unit
>>> with_unit(BENCHMARK_KIND, "ms").unit
'ms'
>>> with_unit(BENCHMARK_KIND, "ms").scale
1000.0
>>> with_unit(BENCHMARK_KIND, "min", scale=1 / 60).unit
'min'

    feu.benchmark.trend ¶

    Contain functions to show the trend of the pytest-benchmark results.

    The results are the JSON files saved by pytest-benchmark (for example by a scheduled workflow). The functions load the runs of the last days, detect the benchmarks that are slower than their recent median, and make a Markdown table.

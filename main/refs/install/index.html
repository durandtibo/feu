    feu.install.PipInstaller dataclass ¶

    Bases: Installer

    Implement a pip package installer.

    The package dependencies are resolved first, and then installed with a single python -m pip install command, where python is the interpreter that runs feu (sys.executable). The packages are therefore installed in the environment that is checked by the compatibility functions, and not in the one of the first pip found on the PATH.

    Parameters:

    Name Type Description Default
    arguments str | Sequence[str]

    Optional arguments to pass to pip install, e.g. "--upgrade". A string is split once with shlex.split; a list or a tuple of strings is used as is.

    		 ()

    Raises:

    Type Description
    RuntimeError

    When installing, if pip is not available in the interpreter that runs feu.
    Example 
    >>> from feu.install import PipInstaller
>>> installer = PipInstaller()
>>> installer
PipInstaller(arguments=())

    feu.install.install_package_closest_version ¶

    install_package_closest_version(
    installer: InstallerSpec,
    package: PackageSpec,
    *,
    target: Target | None = None,
    registry: Registry[type[Installer]] | None = None,
) -> None

    Install a package and associated packages by using the specified installer.

    This function finds the closest valid version if the specified version is not compatible with the target. By default, the target is the current environment: the Python version, the free-threaded flag, the OS and the CPU architecture.

    The package version is a version request: an exact version ('2.0.2'), a wildcard ('2.*') or '' for the latest version. A request is resolved to the latest compatible version. If that version lies in an open-ended range, the request itself is installed, so the installer picks the real latest release.

    Parameters:

    Name Type Description Default
    installer InstallerSpec

    The installer specification.

    		 required
    package PackageSpec

    The package specification.

    		 required
    target Target | None

    The compatibility target. None means the current environment (resolve_target()).

    		 None
    registry Registry[type[Installer]] | None

    The installer registry. None means the default registry.

    		 None

    Raises:

    Type Description
    RuntimeError

    If no installer is registered for the installer name, or if the tool of the installer is not available.
    UnsupportedVersionError

    If no version of the package is valid for the target, or if no known version satisfies a wildcard request.
    ValueError

    If the package version is not a valid version request.
    CalledProcessError

    If the installation command fails.
    Example 
    >>> from feu.install import InstallerSpec, install_package_closest_version
>>> from feu.utils.package import PackageSpec
>>> install_package_closest_version(
...     installer=InstallerSpec("pip"), package=PackageSpec(name="pandas", version="2.2.2")
... )  # doctest: +SKIP

    feu.install.resolver ¶

    Main functions¶

    feu ¶

    Root package of feu.

    The public names are imported lazily (PEP 562): import feu does not import any submodule, so it does not import any optional library. from feu import compare_version imports feu.version the first time it is used.

    feu.InstallerSpec dataclass ¶

    Define a dataclass to represent an installer specification.

    Parameters:

    Name Type Description Default
    name str

    The installer name.

    		 required
    arguments str | Sequence[str]

    The optional installer arguments. A string is split once with shlex.split; a list or a tuple of strings is used as is. The arguments are stored as a tuple.

    		 ()

    Raises:

    Type Description
    TypeError

    If arguments is neither a string nor a list or tuple of strings.
    Example 
    >>> from feu.install import InstallerSpec
>>> installer1 = InstallerSpec("pip")
>>> installer1
InstallerSpec(name='pip', arguments=())
>>> installer2 = InstallerSpec("pip", arguments="-U --pre")
>>> installer2
InstallerSpec(name='pip', arguments=('-U', '--pre'))
>>> installer3 = InstallerSpec("pip", arguments=["-U", "--pre"])
>>> installer3 == installer2
True

    feu.PackageSpec dataclass ¶

    Define a dataclass to represent a package specification.

    Parameters:

    Name Type Description Default
    name str

    The package name.

    		 required
    version str | None

    The package version request: an exact version ("2.4.0"), a wildcard ("2.4.*") or ""/None for the latest version. The string representation pins the version with == unless the request is the latest version. None is stored as "".

    		 ''
    extras Sequence[str] | None

    Optional package extra dependencies. A list is stored as a tuple.

    		 ()
    Example 
    >>> from feu.utils.package import PackageSpec
>>> pkg1 = PackageSpec("my_package")
>>> pkg1
PackageSpec(name='my_package', version='', extras=())
>>> str(pkg1)
'my_package'
>>> pkg2 = PackageSpec("my_package", version="1.2.3")
>>> pkg2
PackageSpec(name='my_package', version='1.2.3', extras=())
>>> str(pkg2)
'my_package==1.2.3'
>>> pkg3 = PackageSpec("my_package", version="1.*", extras=["security", "socks"])
>>> pkg3
PackageSpec(name='my_package', version='1.*', extras=('security', 'socks'))
>>> str(pkg3)
'my_package[security,socks]==1.*'

    feu.Target dataclass ¶

    Identify the environment a package compatibility constraint applies to.

    Parameters:

    Name Type Description Default
    python_version str

    The Python version, e.g. "3.11". Must be a "major.minor" string, without a free-threaded t suffix.

    		 required
    free_threaded bool

    True for a free-threaded (no-GIL) Python build, e.g. 3.14t. Defaults to False.

    		 False
    os str | None

    The operating system, e.g. "linux", "macos", "windows". None means "any OS" when used as a registry entry, and "unspecified" when used as a lookup target.

    		 None
    arch str | None

    The CPU architecture, e.g. "x86_64", "arm64". None means "any architecture" when used as a registry entry, and "unspecified" when used as a lookup target.

    		 None

    Raises:

    Type Description
    ValueError

    if python_version is not a "major.minor" string, or if os/arch is not one of the supported values.
    Example 
    >>> from feu.compat.target import Target
>>> Target(python_version="3.14", free_threaded=True, os="linux", arch="x86_64")
Target(python_version='3.14', free_threaded=True, os='linux', arch='x86_64')

    feu.find_closest_version ¶

    find_closest_version(
    pkg_name: str,
    pkg_version: str | None,
    target: Target,
    *,
    registry: CompatRegistry | None = None,
) -> str

    Find the closest valid version for a package using the default registry.

    Parameters:

    Name Type Description Default
    pkg_name str

    The package name to check (e.g., "numpy").

    		 required
    pkg_version str | None

    The requested package version: an exact version, a wildcard (e.g. "2.*") or ""/None for the latest version.

    		 required
    target Target

    The compatibility target.

    		 required
    registry CompatRegistry | None

    The compatibility registry. None means the default registry.

    		 None

    Returns:

    Type Description
    str

    The closest valid version as a string. An exact version is returned unchanged if it is valid or if the package is not configured for the target. A wildcard or empty request is resolved to the latest compatible version, or returned unchanged if it lies in an open-ended range (see CompatRegistry.find_closest_version).

    Raises:

    Type Description
    UnsupportedVersionError

    If no package version is valid for the given target, or if no known version satisfies a wildcard request.
    ValueError

    If pkg_version is not a valid version request.
    Example 
    >>> from feu.compat import find_closest_version, Target
>>> find_closest_version(
...     pkg_name="numpy", pkg_version="2.0.2", target=Target(python_version="3.11")
... )
'2.0.2'

    The installer specification.

    		 required
    package PackageSpec

    		 required
    registry Registry[type[Installer]] | None

    The installer registry. None means the default registry.

    		 None

    feu.install_package_closest_version ¶

    install_package_closest_version(
    installer: InstallerSpec,
    package: PackageSpec,
    *,
    target: Target | None = None,
    registry: Registry[type[Installer]] | None = None,
) -> None

    Install a package and associated packages by using the specified installer.

    This function finds the closest valid version if the specified version is not compatible with the target. By default, the target is the current environment: the Python version, the free-threaded flag, the OS and the CPU architecture.

    The package version is a version request: an exact version ('2.0.2'), a wildcard ('2.*') or '' for the latest version. A request is resolved to the latest compatible version. If that version lies in an open-ended range, the request itself is installed, so the installer picks the real latest release.

    Parameters:

    Name Type Description Default
    installer InstallerSpec

    The installer specification.

    		 required
    package PackageSpec

    The package specification.

    		 required
    target Target | None

    The compatibility target. None means the current environment (resolve_target()).

    		 None
    registry Registry[type[Installer]] | None

    The installer registry. None means the default registry.

    		 None

    Raises:

    Type Description
    RuntimeError

    If no installer is registered for the installer name, or if the tool of the installer is not available.
    UnsupportedVersionError

    If no version of the package is valid for the target, or if no known version satisfies a wildcard request.
    ValueError

    If the package version is not a valid version request.
    CalledProcessError

    If the installation command fails.
    Example 
    >>> from feu.install import InstallerSpec, install_package_closest_version
>>> from feu.utils.package import PackageSpec
>>> install_package_closest_version(
...     installer=InstallerSpec("pip"), package=PackageSpec(name="pandas", version="2.2.2")
... )  # doctest: +SKIP

    feu.resolve_target ¶

    resolve_target(
    python_version: str | None = None,
    *,
    free_threaded: bool | None = None,
) -> Target

    Resolve the Target of an environment.

    The platform (OS and CPU architecture) is always the current one. The Python version and the free-threaded flag can be chosen, e.g. by a CI matrix that checks other Python versions, and fall back to the current interpreter.

    If python_version ends with t, the target is a free-threaded build. In that case, free_threaded=False is invalid because it contradicts the t suffix.

    Parameters:

    Name Type Description Default
    python_version str | None

    The Python version, e.g. "3.11" or "3.14t". If not provided, the current python version is used.

    		 None
    free_threaded bool | None

    Whether the target is a free-threaded build. If not provided, it is inferred from python_version or the current interpreter's free-threaded status.

    		 None

    Returns:

    Type Description
    Target

    The resolved target, with the current OS and architecture.

    Raises:

    Type Description
    ValueError

    if python_version ends with t and free_threaded=False is specified.
    Example 
    >>> from feu.compat.target import resolve_target
>>> target = resolve_target(python_version="3.14t")
>>> target.python_version, target.free_threaded
('3.14', True)

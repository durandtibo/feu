    feu.utils.http.fetch_data ¶

    fetch_data(
    url: str,
    *,
    timeout: float = 10.0,
    headers: Mapping[str, str] | None = None,
    params: Mapping[str, Any] | None = None,
    accept: str | None = None,
) -> dict[str, Any]

    Retrieve the JSON data for a given URL.

    This function performs an HTTP GET request and parses the response body as JSON. It configures a retry policy for transient errors (e.g., 429, 500, 502, 503, 504), handles network and timeout failures, validates the HTTP response, and returns the parsed JSON payload. Any unrecoverable error is raised as a RuntimeError with a clear message.

    Parameters:

    Name Type Description Default
    url str

    The URL.

    		 required
    timeout float

    The number of seconds to wait for the server to send data before giving up.

    		 10.0
    headers Mapping[str, str] | None

    Optional HTTP headers to send.

    		 None
    params Mapping[str, Any] | None

    Optional query parameters.

    		 None
    accept str | None

    Optional value of the Accept header. An Accept entry of headers takes precedence.

    		 None

    Returns:

    Type Description
    dict[str, Any]

    The parsed JSON object returned.

    Raises:

    Type Description
    RuntimeError

    If the request times out, if a network or HTTP error occurs, or if the response body contains invalid JSON.
    MissingPackageError

    If requests is not installed.
    Example 
    >>> from feu.utils.http import fetch_data
>>> data = fetch_data("https://pypi.org/pypi/requests/json")  # doctest: +SKIP

    feu.utils.http.fetch_response ¶

    fetch_response(
    url: str,
    *,
    timeout: float = 10.0,
    headers: Mapping[str, str] | None = None,
    params: Mapping[str, Any] | None = None,
    accept: str | None = None,
) -> Response

    Retrieve data from a given URL with automatic retry logic.

    This function performs an HTTP GET request with a configured retry policy for transient errors (429, 500, 502, 503, 504), with exponential backoff and up to 5 retry attempts on https:// and http://. The request has a User-Agent: feu/<version> header. The function validates the HTTP response and raises detailed errors for failures. The session is closed before the function returns, so streaming is not supported.

    Parameters:

    Name Type Description Default
    url str

    The URL to fetch.

    		 required
    timeout float

    The number of seconds to wait for the server to send data before giving up. Defaults to 10.0.

    		 10.0
    headers Mapping[str, str] | None

    Optional HTTP headers to send.

    		 None
    params Mapping[str, Any] | None

    Optional query parameters.

    		 None
    accept str | None

    Optional value of the Accept header. An Accept entry of headers takes precedence.

    		 None

    Returns:

    Type Description
    Response

    A requests.Response object containing the HTTP response.

    Raises:

    Type Description
    RuntimeError

    If the request times out, or if a network/HTTP error occurs.
    MissingPackageError

    If requests is not installed.
    Example 
    >>> from feu.utils.http import fetch_response
>>> response = fetch_response("https://pypi.org/pypi/requests/json")  # doctest: +SKIP
>>> response.json()  # doctest: +SKIP

    feu.utils.package.PackageSpec dataclass ¶

    Define a dataclass to represent a package specification.

    Parameters:

    Name Type Description Default
    name str

    The package name.

    		 required
    version str | None

    The package version request: an exact version ("2.4.0"), a wildcard ("2.4.*") or ""/None for the latest version. The string representation pins the version with == unless the request is the latest version. None is stored as "".

    		 ''
    extras Sequence[str] | None

    Optional package extra dependencies. A list is stored as a tuple.

    		 ()
    Example 
    >>> from feu.utils.package import PackageSpec
>>> pkg1 = PackageSpec("my_package")
>>> pkg1
PackageSpec(name='my_package', version='', extras=())
>>> str(pkg1)
'my_package'
>>> pkg2 = PackageSpec("my_package", version="1.2.3")
>>> pkg2
PackageSpec(name='my_package', version='1.2.3', extras=())
>>> str(pkg2)
'my_package==1.2.3'
>>> pkg3 = PackageSpec("my_package", version="1.*", extras=["security", "socks"])
>>> pkg3
PackageSpec(name='my_package', version='1.*', extras=('security', 'socks'))
>>> str(pkg3)
'my_package[security,socks]==1.*'

    feu.utils.registry ¶

    Contain a generic registry to register and look up values by name.

    feu.utils.registry.Registry ¶

    Bases: Generic[T]

    Register values and look them up by key.

    This is the only implementation of "register and look up by name" of feu: the installer registry and the dependency resolver registry are instances of it.

    Parameters:

    Name Type Description Default
    kind str

    What the registry holds, e.g. "installer". It is used in the error messages.

    		 required
    normalize Callable[[str], str] | None

    A function applied to every key before it is stored or looked up, e.g. packaging.utils.canonicalize_name or str.lower. None means the key is used as is.

    		 None
    Example 
    >>> from feu.utils.registry import Registry
>>> registry = Registry[int]("number", normalize=str.lower)
>>> registry.register("One", 1)
>>> registry.find("ONE")
1
>>> "one" in registry
True
>>> registry.keys()
['one']

    feu.utils.platform.is_free_threaded ¶

    is_free_threaded() -> bool

    Indicate whether the running Python interpreter is a free- threaded build with the GIL disabled.

    Free-threaded builds (PEP 703 <https://peps.python.org/pep-0703/>_) expose sys._is_gil_enabled, which is only present starting from Python 3.13 free-threaded builds. On any other build, or when the GIL has been re-enabled at runtime, this returns False.

    Returns:

    Type Description
    bool

    True if the interpreter is running without the GIL, otherwise False.
    Example 
    >>> from feu.utils.platform import is_free_threaded
>>> is_free_threaded()  # doctest: +SKIP
False
